\begin{abstract}
One example of every accessibility feature of this sandbox, on one page.
\end{abstract}
\maketitle

This page exists to be tested. Read it with a screen reader as a web page,
then open its tagged PDF (the link at the top right) and read that, or
look at the Tags panel in Adobe Acrobat. Each part says what to listen or
look for.

\section{Headings}

The title of the page is a level 1 heading and each section a level 2
heading. A subsection is one level further down, and so is the head of a
theorem inside it.

\subsection{A subsection with a theorem}

\begin{theorem}[Pythagoras]
In a right triangle with legs $a$ and $b$ and hypotenuse $c$, we have
$a^2+b^2=c^2$.
\end{theorem}

\section{Formulas}

Each formula carries MathML, and these commands add what the notation
means, so that it is read correctly:

\begin{itemize}
\item an absolute value, $\xmabs{x-3}$, and a determinant, $\xmdet{A}$;
\item a length with a unit, $5\,\xmunits{cm}$, and an angle, $90\xmdeg$;
\item a point, $\xmpoint{2,5}$, and an interval, $\xminterval{[0,1)}$;
\item a composition, $\xmcompose{f}{g}(x)$, and an inverse, $\xminv{f}(x)$;
\item a dot product of vectors, $\xmdot{\xmvec{u}}{\xmvec{v}}$.
\end{itemize}

A displayed formula:
\[
\xmabs{a+b}\le\xmabs{a}+\xmabs{b}.
\]

\section{Blanks and answers}

A line to write on is announced as a blank. Name: \xmblank[2in]

\begin{problem}
An answer box. On the web page it is a box to type in; in the PDF it is a
blank. $2+2=\answer{4}$
\end{problem}

\section{Lists and choices}

A numbered list is tagged as a list, with its items:

\begin{enumerate}
\item Read the question.
\item Choose an answer.
\item Check it.
\end{enumerate}

\begin{problem}
On the web page these choices are radio buttons; in the PDF they are a
list. Which number is prime?

\begin{multipleChoice}
\choice{$21$}
\choice[correct]{$23$}
\choice{$27$}
\end{multipleChoice}
\end{problem}

\section{A table}

The first row holds column headers and the first column holds row headers.
Moving through the cells, a screen reader announces the headers of each one.

\begin{center}
\begin{tblr}{colspec={lcc}, hlines, vlines, rowhead=1, xmcolhead=1,
    caption={Quiz scores}, summary={One row for each student, one column for each quiz.}}
Student & Quiz 1 & Quiz 2 \\
Ada     & 9      & 10     \\
Emmy    & 8      & 7      \\
\end{tblr}
\end{center}

\section{Words in another language}

The French phrase \xmlang{fr}{raison d'\^etre} is marked as French, so a
screen reader can switch voice for it and back.

The same works for other alphabets. The Ukrainian mathematician Mykhailo
Kravchuk wrote his name \xmlang{uk}{Михайло Кравчук}, and the Greek word
\xmlang{el}{τέλειος} means complete.
